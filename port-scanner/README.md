# Python TCP 端口扫描器

一个使用 Python `socket` 编写的简单 TCP 端口扫描器，用于学习网络编程、Socket 通信以及基础端口扫描原理。

## 项目简介

本项目通过 Python Socket 对指定目标的 TCP 端口进行连接测试。

如果能够成功建立 TCP 连接，则认为该端口处于开放状态，并输出对应端口及常见服务名称。

项目主要用于 **Python 编程和网络安全基础学习**。

## 功能

* TCP 端口扫描
* 支持 IPv4
* 支持指定端口范围
* 支持交互式输入
* 支持命令行参数
* 显示开放端口
* 识别常见端口对应的服务
* 统计开放端口数量
* 统计扫描耗时
* 检查端口范围是否合法

## 使用方法

### 方法一：交互式运行

直接运行：

```bash
python main.py
```

然后根据提示输入：

```text
请输入目标IP：127.0.0.1
请输入起始端口：1
请输入结束端口：1000
```

### 方法二：命令行参数

也可以直接指定目标和端口范围：

```bash
python main.py 127.0.0.1 1 1000
```

参数格式：

```text
python main.py <目标IP> <起始端口> <结束端口>
```

## 实现原理

程序使用 Python 的 `socket` 模块创建 TCP Socket：

```python
socket.socket(socket.AF_INET, socket.SOCK_STREAM)
```

然后对指定范围内的端口逐个尝试建立 TCP 连接：

```python
s.connect((target, port))
```

连接成功，则将端口加入开放端口列表：

```python
open_ports.append(port)
```

最后由 `main.py` 统一输出扫描结果并统计扫描时间。
